# Spark Shop implementation plan

- M0: Create strict TypeScript / Vite / Preact project, test and lint scripts.
- M1: Deterministic decimal economy, station cycles, managers, saves and tests.
- M2: Zones, milestones, offline limits, prestige, research and Fault Hunt.
- M3: Reward placement eligibility, exact-once rewards and two-profile simulation.
- M4: Portrait responsive interface, all screens, tutorial and English/Turkish text.
- M5: Achievements, daily missions, weekly events, login, notifications and mocks.
- M6: Capacitor Android, AdMob consent/reward events, purchases and native lifecycle.
- M7: Release documentation, full checks, browser verification and Android build attempt.

## Verification
- Typecheck and unit tests before each milestone commit.
- Run deterministic seven-day simulations for both ad profiles.
- Build browser assets, sync Android and attempt release bundle.
- Clearly record environment and physical-device verification limits.
