# Spark Shop assets

- Circuit board, component shapes, traces and soldering iron: original inline SVG
  in `src/ui/Board.tsx`; generic fictional circuitry, not a real repair schematic.
- Spark logo and Android launcher/splash mark: original Android vector paths and
  text/CSS. Android system splash uses the mark; HTML launch screen shows the exact
  official title. Final store 512×512 and 1024×500 raster exports remain to produce.
- Device icons: Unicode geometric placeholders; station names and era content supply
  context. Replace with original device SVGs if higher art fidelity is desired.
- Font: local system UI fonts; no downloaded font files or external font service.
- Sounds: short WebAudio oscillators; no sampled audio or music assets.
- Animations: CSS progress, button feedback, fault glow and floating amounts, with
  reduced-motion support. Haptics use the platform plugin.
- Tutorial, store and release screenshot briefs: original text. `artifacts/workshop.png`
  is a local browser QA capture, not a final store screenshot; PNG QA files are ignored.
- No external stock images, recorded music, copied device logos or licensed game art.
- Unused template launcher/splash raster images were removed; custom original
  vectors are wired as the displayed launcher and splash assets.

Google AdMob, Google Play, Capacitor and RevenueCat names in technical/privacy
documents identify integrated services. Device names inside gameplay are fictional;
the publisher should still perform naming/trademark clearance before release.
