## Device atlas — public/art/device-atlas.png

Use case: stylized-concept. Asset type: game device sprite atlas for the existing Android game Spark Shop. Input image is a STYLE REFERENCE ONLY, not an edit target. Generate ONE clean sprite atlas containing exactly 30 separate electronics repair devices in a precise 6 columns by 5 rows equal-cell grid. No gutters beyond consistent generous cell padding. Every device fully contained in its cell, centered, same orthographic three-quarter viewpoint, warm amber workshop lighting, tactile finely detailed materials, realistic premium 3D-rendered vintage/modern game-item art matching the radio/cassette/TV art in the reference. Background of every cell uniformly very dark forest green #0b1c11, no panels, no frames, no typography, no UI, no logos, no words, no watermarks. Keep each device within central 80% of its cell so CSS can safely use the atlas. Landscape 6:5 canvas, highest practical resolution. Row 1 from left to right: wooden 1980s radio; portable cassette player with headphones; wooden tube television; analog hi-fi receiver; reel-to-reel tape recorder; arcade circuit board. Row 2: 1990s plastic CRT television; VHS video deck; fictional early game console with gamepad; satellite receiver; disc deck; stereo rack. Row 3: feature mobile phone; handheld game console; portable CD player; MP3 player; compact digital camera; GPS navigator. Row 4: modern smartphone; laptop; quadcopter drone; tablet; smartwatch; desktop PC tower. Row 5: electric scooter; EV wall charging unit; UPS battery unit; smart-home hub; solar inverter; industrial power controller. Exactly six individual items per row, exactly five rows. Only fictional unbranded devices. Do not include any screenshots, controls, labels or text from the reference.

## Circuit board — public/art/repair-board.png

Use case: stylized-concept. Project-bound game hero background asset, NOT a UI screenshot. The attached image is a style reference. Create a single wide landscape close-up of the electronics repair circuit board from the reference's central workbench panel: tactile aged deep green PCB with copper traces, blue electrolytic capacitors, orange/brown resistors, a black integrated circuit in the center, a vintage metal electronics chassis partly visible at the left edge and a soldering iron partly visible at the right on a dark wooden workbench. Match the luxurious realistic 3D illustration, warm amber workshop lighting and deep forest green palette of the reference. Wide 3:1 composition with all key components in the central horizontal band; viewed three-quarter from above, board fills most of image. It is an interactive game background and active faults will be added in code: NO glowing components, NO sparks, NO spotlights identifying a particular component. No text, letters, numbers, branding, UI, borders, screen frames, menus, buttons or typography whatsoever. The entire output is only the detailed board scene. High detail, crisp copper traces, believable electronics, no excessive blur.
